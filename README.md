## 🚀 Live Demo & Deployment Guide to GitHub Pages

Dự án này được xây dựng hoàn toàn bằng **HTML5, Vanilla CSS3 và Vanilla JavaScript**, không phụ thuộc vào bất kỳ thư viện ngoài (zero-dependencies) hay bước build phức tạp nào. Bạn có thể up trực tiếp lên GitHub và bật GitHub Pages chạy ngay lập tức.

### Cách 1: Đưa lên GitHub & Bật GitHub Pages (Khuyên dùng)
1. Mở terminal trong thư mục này và khởi tạo git:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Google Antigravity landing page"
   git branch -M main
   ```
2. Tạo một Repository mới trên GitHub (ví dụ: `google-antigravity` hoặc `tuanc-portfolio`).
3. Push code lên GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
4. Trên GitHub: Vào **Settings** → **Pages** → Trong mục **Build and deployment** chọn:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
   - Nhấn **Save**.
5. Sau 1 phút, website tĩnh của bạn sẽ online tại: `https://<your-username>.github.io/<your-repo-name>/` 🎉
